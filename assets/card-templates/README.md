# Card template assets

このディレクトリには、プロフィールカードのデザインごとに使用する素材を配置します。
`default` と同じ階層へ別のデザイン名を追加すると、将来テンプレートを増やせます。

```text
<template-name>/
  front/                 # カード表面
    base.png             # 背景となる完成サイズの PNG
    icons/               # 値として配置するアイコン素材
    value-frames/        # 文字や値を配置する枠素材
    icon-frames/         # アイコンを配置する枠素材
  back/                  # カード裏面（front と同じ構成）
```

ベース画像は PNG、差し替え可能な枠・アイコンは透過 SVG を基本形式とします。表裏の
`base.png` は同じ寸法（現在のダミーは 1200 x 760、約 1.58:1）で用意してください。
各素材はレンダラーが参照する固定名から始め、正式デザイン受領時に同じ用途のファイルを
置き換えます。ダミー素材にはブランドロゴや第三者の著作物を含めません。
